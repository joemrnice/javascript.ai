Objects & Arrays

Objects are JavaScript's one true composite structure — arrays, functions, dates, even classes are objects underneath. Get comfortable with the object model and the rest of the language gets easier.

Object literals and property access

objects.js
const user = {
  name: "Amara",
  age: 28,
  ["computed_" + "key"]: true, // computed property names
  greet() { return `Hi, I'm ${this.name}`; }, // method shorthand
};

user.name;          // dot notation — "Amara"
user["age"];        // bracket notation — required for dynamic keys
const key = "name";
user[key];           // "Amara" — dynamic access

user.address?.city; // optional chaining — undefined instead of a throw
user.address ??= {}; // nullish assignment — sets a default only if null/undefined

Destructuring

destructuring.js
const person = { name: "Kwame", location: { city: "Accra", country: "Ghana" } };

// Object destructuring, with renaming, defaults, and nesting
const {
  name,
  role = "guest",
  location: { city },
} = person;

// Array destructuring — position-based, works with any iterable
const [first, second, ...rest] = [10, 20, 30, 40];
// first = 10, second = 20, rest = [30, 40]

// Swapping values with no temp variable
let a = 1, b = 2;
[a, b] = [b, a];

// Destructuring in function parameters — extremely common in React-style code
function render({ title, size = "md" }) {
  return `${title} (${size})`;
}

Spread and rest

The same ... syntax means two different things depending on position: spread expands an iterable, rest collects remaining items.

spread-rest.js
// Spread — copying and merging (shallow!)
const base = { theme: "dark", size: "md" };
const merged = { ...base, size: "lg" }; // { theme: "dark", size: "lg" }

const arr1 = [1, 2];
const arr2 = [3, 4];
const combined = [...arr1, ...arr2]; // [1, 2, 3, 4]

// Rest — the inverse, collecting into an array
function sum(...nums) { return nums.reduce((a, b) => a + b, 0); }
const [head, ...tail] = [1, 2, 3]; // head = 1, tail = [2, 3]
Shallow, not deep

Spread only copies one level deep. { ...base, nested: base.nested } still shares the same nested object by reference. For a true deep copy use structuredClone(obj) (built into modern browsers and Node 17+), not JSON.parse(JSON.stringify(obj)), which silently drops functions, undefined, and Date objects.

The array methods that matter

MethodMutates?Use it for
map()NoTransform every item, same length out
filter()NoKeep items matching a condition
reduce()NoFold an array into a single value (sum, object, grouped map)
find() / findIndex()NoFirst match / its index
some() / every()NoBoolean checks across the array
flatMap()NoMap then flatten one level — great for 1-to-many transforms
sort()YesIn-place sort — always pass a comparator for numbers
splice()YesInsert/remove in place
slice()NoCopy a portion — the non-mutating sibling of splice
reduce-patterns.js
const orders = [
  { id: 1, category: "books", total: 20 },
  { id: 2, category: "tech",  total: 500 },
  { id: 3, category: "books", total: 15 },
];

// Sum
const grandTotal = orders.reduce((acc, o) => acc + o.total, 0); // 535

// Group by — reduce can build any shape, not just numbers
const byCategory = orders.reduce((acc, o) => {
  (acc[o.category] ??= []).push(o);
  return acc;
}, {});
// { books: [order1, order3], tech: [order2] }

// A frequent interview gotcha:
[10, 1, 2].sort();          // [1, 10, 2] — sorts as STRINGS by default!
[10, 1, 2].sort((a, b) => a - b); // [1, 2, 10] — always pass a comparator for numbers

Object utility methods worth knowing

object-utils.js
Object.keys(obj);     // ["name", "age"] — own enumerable keys
Object.values(obj);   // ["Amara", 28]
Object.entries(obj);  // [["name","Amara"], ["age",28]] — great for for...of
Object.fromEntries([["a", 1], ["b", 2]]); // { a: 1, b: 2 } — the inverse

Object.freeze(obj);   // shallow-freezes — top-level reassignment throws (in strict mode)
Object.isFrozen(obj); // true

Object.assign({}, obj1, obj2); // shallow merge — spread syntax is now preferred

Interview questions on this topic

Use structuredClone(obj), available natively in modern browsers and Node 17+. It handles nested objects, arrays, dates, maps, and sets correctly. Avoid JSON.parse(JSON.stringify(obj)) — it silently loses functions, undefined values, Date becomes a string, and it throws on circular references.

map() returns a new array built from the callback's return values, and is meant for transformations. forEach() always returns undefined and is meant purely for side effects (like logging). Using forEach when you meant map — or building an array by pushing inside a forEach — is a common code-review flag.

The idiomatic one-liner is [...new Set(array)] — Set only stores unique values, and the spread converts it back into an array. For arrays of objects, dedupe by a key using a Map: [...new Map(arr.map(o => [o.id, o])).values()].
